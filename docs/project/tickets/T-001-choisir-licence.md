## But
Le repo est public sans licence : par défaut, personne n'a le droit de réutiliser le code.

## Critères de fin
- [ ] Licence choisie (MIT, GPL ou aucune) et notée dans DECISIONS.md.
- [ ] Fichier `LICENSE` ajouté si une licence est choisie.

## Contexte
Décision de l'utilisateur. Ensuite, ajout du fichier : Haiku.
